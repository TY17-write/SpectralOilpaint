# 色輸送修正後のカオステスト — 2026-09-29

専用 Chrome / WebGPU でアプリと同じエンジンを操作。ユーザーのブラウザーや絵は操作せず、製品の描画処理もこの試験では変更していない。

## 実施条件と結果

- 7色、濃度2%・15%・100%、2層／3層で各90本、計270本のランダム筆跡。半径2〜64px、筆圧0.001〜1、単押し・折り返し・キャンバス外への移動・7回に1回の空筆を混在。GPUエラー、非数、負の厚さ、顔料量が総厚を超えるセルは検出されなかった。
- 描画後20秒、傾きを下・右・上・左へ各60°で切り替え。放置中の絵具・顔料の増加なし。薄い2条件は端から流出し、濃度100%は全量が静止。乾燥後の床の厚さは直前の塗膜厚の総和と一致。
- 半径16・48・96pxの同圧単押し：中央厚さは全て28.125µm。
- 赤青の交点への低筆圧の白い単押し：RGB (76,74,73) のまま。以前の円形の突然の変色は出なかった。
- 微小接触の専用試験でも、既存2／3層への筆圧0〜0.001でRGB成分差3以下を確認。
- 青黄の厚い塊、顔料15%、傾き15°、60秒：全観測時点でピンク0画素。最大正規化スペクトル誤差0.0392で回帰基準0.05未満。前回修正と同じ結果が再現した。
- 同厚の濃度100／50／10／2%で下地の見え方が段階的に増加。湿潤下地ではチューブ濃度でも混色、乾燥下地では上塗りとなる既存試験が通った。
- 24本の多色交差とその後3秒の流動、空筆の往復を再度目視確認。

## 残る見た目の限界

新しい明確な数値破綻は今回の条件では検出されなかった。一方、色筋・筆毛の跡・厚い塗膜の表面だけを拾う表現は弱い。最上層を均質に混ぜる近似のため、繰り返し混ぜると滑らかに濁り、空筆も帯状に見える。多色を大量に混ぜて濁ること自体を異常とは判定していない。

この結果は全ての色・厚さ・時間・操作順で自然であることの保証ではない。特にこのランダム試験の最大厚さは約1.28mmで、3mmの厚塗りは別の青黄60秒試験で補っている。実際のマウス／ペン入力遅延は測定していない。
