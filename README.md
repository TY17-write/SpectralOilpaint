# 油彩アトリエ

同梱の「油彩ペイントエンジン 実装仕様.md」を基にした WebGPU 実装です。参照コードと顔料テーブルは `reference/` をそのまま使用します。

## 起動

1. Node.js が利用できる状態で、このフォルダーの `start.cmd` を実行します。追加パッケージのインストールは不要です。
2. Chrome または Edge で <http://localhost:8080> を開きます。
3. 終了するときはサーバーのウィンドウで Ctrl+C を押します。

コマンドで起動する場合は、このディレクトリで `npm start`。HTML の直接ダブルクリックでは WebGPU とテーブル読み込みが動作しません。

## 操作

- 色、筆の半径、顔料の濃さを選び、キャンバスをドラッグします。ペンの筆圧にも対応しています。
- 「混ぜる」は空の筆です。既存の絵具を拾い、混ぜて塗り戻します。
- 「描く」でも湿った絵具には色が混ざります。「混ぜる」は新しい絵具を補充せず、既存の絵具を動かします。混ぜずに上塗りしたいときは下地を乾かしてください。
- 濃さを下げてキャンバスを傾けると流れます。
- 四辺は開放境界です。外へ流れた分の絵具は消え、端でせき止められません。静止・乾燥した絵具は、端にあるだけでは消えません。
- 「今すぐ乾かす」で湿潤層を乾燥床へ焼き込みます。自動乾燥も選べます。
- 「画像を保存」で PNG を保存します。編集可能な状態の保存・復元や Undo は未実装です。
- 解像度・層数を変えた場合は「新しいキャンバス」で適用します。現在の絵は消えます。

## 主な実装

- 38 波長の吸収・散乱記述子、顔料量による保存形混色、有限厚 Kubelka–Munk 合成。
- 2 / 3 湿潤層、筆圧による貫入、双方向の絵具交換、層統合、ブラシ補充。
- C 格子、半ラグランジュ速度移流、粘性、底面摩擦、赤黒 GS、速度クランプ、保存形の層輸送。
- アクティブタイルと indirect dispatch。正本のキャンバス状態は一組です。
- GPU の半精度変換の丸め差を吸収する明示的な最近接・偶数丸め。
- 乾燥、床への焼き込み、GGX 陰影、PNG 保存、GPU エラー表示。

## 2026-09-29 の白い大筆・矩形線の修正

- フラックスに計算世代を付け、別の層・軸・サブステップ・フレームの古い値を読まないようにしました。アクティブ領域の外に残ったスクラッチ値が境界で再利用される問題への対策です。
- ブラシ外周を距離の二乗で判定し、平方根の誤差で円の外のセルが更新される問題を防ぎます。
- 輸送で層の間に空きができたセルは、ブラシ処理前に占有層を下へ揃えます。
- 陰影用の高さに 7×7 の平滑化を適用し、一画素の段差が黒い輪郭に見える現象を抑えました。顔料、実際の厚み、流体計算は平滑化しません。

更新を反映するにはページを再読み込みしてください。必要な画像は先に保存してください。修正前に作られた不正な高さは既存キャンバスに残るため、新しいキャンバスで確認します。

## 上塗り・流動の見直し

大筆は最大 2 px 間隔で補間し、移動距離に応じて堆積・交換量を補正します。初回の単押しには移動用補正をかけません。粘度は対数補間、流動の開始・停止は連続的な重みへ変更しました。

透明度と混色の再修正では、光学係数を通常の塗膜厚に合わせて見直しました。同じ厚さなら顔料濃度を下げるほど下地が見えます。厚塗りや繰り返し塗りで顔料量が増えれば再び不透明になります。顔料ごとの実測係数ではなく、共通係数を調整した近似です。

湿潤塗膜は、筆が触れる表面とその下の絵具に分けて扱います。筆圧に応じて約15〜100µmの範囲を拾い、筆の絵具と交換します。新しく塗った分だけ以前の表面が下へ押し込まれます。ストロークごとに既存の色を丸ごと統合する処理は行いません。乾燥床の顔料は拾いません。通常モードでは3mmの堆積打ち切りを撤廃しています。

筆の各部分が拾った色を保持し、不均一な接触で細い色筋を残します。規則的な縞やフレームごとのランダムな粒ではなく、各ストロークで固定された接触分布です。筆の向きは最初の移動方向で決まります。2／3層で表面を近似する方式のため、実物の毛の曲がりや任意の深さの層構造までは再現していません。

これらは元仕様からの意図的な変更です。参照モデルとの数値比較には `referenceMode: true`、通常の描画と新しい視覚回帰試験には改訂モデルを使います。実物の油彩を完全に再現するモデルではありません。

## テストの実行

青と黄色の厚い塊を顔料15%・傾き15°で合流させる長時間試験を追加しました。輸送のたびに半精度へ最近接丸めすると微量の混色が波長ごとに失われ、緑がピンクへ変質していました。輸送の色更新に偏りを抑えた決定的な確率的丸めを用い、流出の差し引きも非負の混合重みへ整理しています。色の精度を完全に無限精度にするものではありません。

境界の光沢・陰影は柔らかい照明に調整しています。表示用の凹凸倍率 0.35、湿潤面粗さ 0.38、環境光 0.6／方向光 0.3。絵具の厚さや顔料データを平滑化・変更する調整ではありません。`node tests/browser.mjs lighting.html lighting-comparison.png` で同一塗膜の変更前後を比較できます。

`npm test` は Node.js の顔料・レイアウト検証です。GPU 検証は Windows の標準 Chrome パスを既定とし、専用プロファイルを使います。通常のブラウザー設定やタブには触れません。別の Chrome は `CHROME_PATH` で指定できます。

```text
npm test
npm run test:gpu
npm run test:fluid
npm run test:brush
npm run test:tiles
npm run test:white
npm run test:overpaint
npm run test:flow-default
npm run test:outflow
npm run test:materials
npm run test:contact
npm run test:flow-color
npm run test:surface
npm run test:performance
```

比較用の `tests/brush-reference.json` は同梱済みです。再生成時だけ Python と NumPy が必要です。`python tests/generate_brush_fixture.py` で、変更していない参照実装から生成します。

詳しい測定値、仕様との相違、未達項目は `IMPLEMENTATION_STATUS.md` を参照してください。全受け入れ項目を達成した完成版とは位置づけていません。

## ファイル

| ファイル | 役割 |
|---|---|
| `src/engine.js` | GPU バッファ、パイプライン、フレーム進行、ストローク補間、読み戻し |
| `src/shaders.js` | 層数に応じた WGSL 生成。各パスの必要なバインディングのみ生成 |
| `src/color.js` | 任意 sRGB の分光再構成、CPU 光学計算、半精度パック |
| `src/config.js` | 物理・描画パラメータ |
| `src/app.js` | 画面と入力 |
| `tests/` | 数値検証、GPU 検証、白い大筆の回帰試験 |

`window.oilpaint.config` で実行中の物理パラメータを調整できます。ただし解像度・層数は再生成が必要です。`normalRadius=0` にすると、仕様書 §7.2 の平滑化なしの高さ微分に戻せます。
